# Build Roadmap

## Phase 0 — Environment
Install Cursor, Node.js LTS, Git. Create GitHub and Supabase accounts.

## Phase 1 — Foundation
Initialize Next.js/TypeScript, Tailwind, shadcn/ui, linting, environment configuration, folder structure.

## Phase 2 — Database
Create Supabase migrations, tables, constraints, indexes, seed data.

## Phase 3 — Auth/security
Supabase Auth, role handling, RLS, storage policies.

## Phase 4 — UI foundation
Design system, layouts, navigation, dashboard shell, responsive behavior.

## Phase 5 — Student
Profile → assessment → skill intelligence → career → learning.

## Phase 6 — Opportunities
Internships/jobs → matching → applications → tracking.

## Phase 7 — AI
Resume generation/analyzer, skill/career recommendations, match explanations.

## Phase 8 — Industry
Company, opportunities, applicants, recruitment workflow.

## Phase 9 — Academician
FDP, industrial training, research, consultancy, mentorship.

## Phase 10 — Institution
Students, skill intelligence, internship and placement analytics.

## Phase 11 — Admin
Moderation, management, analytics.

## Phase 12 — Polish
Responsive UI, loading/empty/error states, accessibility, performance.

## Phase 13 — Testing
Unit, integration, RLS, E2E, security, AI validation.

## Phase 14 — Deployment
GitHub → Vercel + Supabase production setup.

Do not advance to a dependent phase until its acceptance criteria pass.
