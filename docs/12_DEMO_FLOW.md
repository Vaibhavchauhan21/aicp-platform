# SIH Demo Flow

## Main story
1. Student logs in.
2. Completes assessment.
3. Sees skill profile.
4. Selects Full Stack Developer.
5. Sees skill gaps such as Docker, System Design, AWS.
6. Receives learning recommendations.
7. Sees a 91% matched internship.
8. Opens explanation of the match.
9. Generates a target-role AI resume.
10. Applies.
11. Recruiter views candidate and shortlists them.
12. Student sees shortlist notification.
13. Institution dashboard shows readiness, internship, and placement analytics.

## WOW moments
- Employability/readiness dashboard.
- Visual skill graph.
- Explainable match score.
- AI resume generation/analyzer.
- Institution-level skill-gap analytics.

## Demo data
Seed realistic but clearly fictional demo users, institutions, companies, opportunities, skills, applications, and analytics. Never use real personal data.
