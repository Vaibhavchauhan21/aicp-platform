# UI/UX Specification

## Global
Responsive web application with accessible navigation, loading states, empty states, error states, confirmation states, and keyboard-friendly forms.

## Core screens
1. Landing
2. Login/signup
3. Student dashboard
4. Skill assessment
5. Skill intelligence
6. Opportunity marketplace
7. Opportunity details
8. Application tracker
9. AI resume builder
10. Digital portfolio
11. Industry dashboard
12. Create opportunity
13. Candidate/application management
14. Academician portal
15. Institution intelligence dashboard

## Navigation
Student: Dashboard, My Skills, Career, Opportunities, Applications, Learning, Resume AI, Portfolio, Profile.

Industry: Dashboard, Opportunities, Applications, Candidates, Learning Programs, Mentorship, Collaboration, Company.

Academician: Dashboard, Opportunities, FDPs, Industrial Training, Research, Consultancy, Mentorship, Profile.

Institution: Dashboard, Students, Skill Intelligence, Internships, Placements, Industry, Analytics, Settings.

## UX priorities
- Show explanations beside recommendations.
- Keep key actions within one or two clicks.
- Use visual readiness/match scores without implying false precision.
- Make the skill-gap → learning → opportunity journey visually obvious.
