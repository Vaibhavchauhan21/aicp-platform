# MVP Scope

## P0 — Must ship
Authentication; profiles; assessments; skill profile; skill-gap analysis; career recommendations; learning recommendations; internship/job marketplace; opportunity matching; application tracking; AI resume builder; AI resume analyzer; digital portfolio; academician portal; industry portal; institution dashboard; collaboration; notifications; admin; search.

## P1 — If core MVP is stable
AI interview preparation; career roadmap; internship readiness; portfolio AI.

## P2
Advanced RAG, broad external LMS/certification integrations, advanced semantic search, richer employer analytics.

## P3
AI mentor, workforce forecasting, national-scale skill intelligence and policy analytics.

## Explicit exclusions from MVP
Mobile apps, custom model training, blockchain certificates, full LMS, video conferencing, payments, Kubernetes/microservices, unnecessary third-party integrations.

## MVP acceptance
The complete student → recruiter → institution journey must function with persisted data and role-correct access.
