# Design System

## Direction
Beautiful, modern, colorful, trustworthy, and professional rather than a generic corporate dashboard.

## Visual language
- Soft gradients used selectively.
- Strong but accessible accent colors.
- Layered cards and subtle depth.
- Rounded components with consistent radius.
- Clear typography hierarchy.
- Data visualizations with accessible contrast.
- Responsive layouts first.

## Components
Buttons, inputs, selects, badges, cards, tabs, dialogs, tables, charts, progress indicators, skill bars, match-score cards, timeline/status components, notification panels.

## Motion
Use subtle transitions for navigation, cards, progress, and status changes. Avoid distracting animation.

## Accessibility
Meet practical WCAG-oriented contrast, focus, keyboard, semantic HTML, and reduced-motion expectations.
